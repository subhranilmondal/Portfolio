# Subhranil Mondal Portfolio — GitHub Pages

This folder is the deploy-ready build. `index.html` is intentionally at the root.

1. Extract `website-demo.zip`.
2. Upload every extracted file and folder to the root of your GitHub repository.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then save.

The build uses relative asset paths, so it works for both user sites and project repositories.
